# Правку видит покупатель — значит, смотреть глазами

Подсчёт тегов в HTML **не является проверкой вёрстки**. 22.09.2026 блок
«Хиты продаж» был собран, проверен разбором HTML — один заголовок, восемь
карточек, кнопка на месте — и отправлен владельцу как готовый. На экране
он шёл вертикальной лентой с огромными карточками: виджет Elementor имел
ширину 380 px при экране 1440, и сетка `auto-fill` схлопнулась в столбец.
Из HTML это не видно вообще никак.

**Правило: пока не сделан скриншот и не сняты размеры, говорить «готово»
нельзя.**

## Как запускать браузер в этом контейнере

Chromium предустановлен. Playwright ставится в свою версию и ждёт другую
сборку — поэтому путь задаётся явно.

Сертификат прокси **не отключать**: TLS-проверка остаётся, просто
прикалывается CA прокси по SPKI.

```bash
S=<scratchpad>
csplit -z -f $S/ca_ -b "%02d.pem" /root/.ccr/ca-bundle.crt '/BEGIN CERTIFICATE/' '{*}' >/dev/null
for f in $S/ca_*.pem; do
  openssl x509 -in "$f" -pubkey -noout | openssl pkey -pubin -outform der \
    | openssl dgst -sha256 -binary | openssl enc -base64
done | sort -u | tr '\n' ',' | sed 's/,$//' > $S/spki.txt
```

```js
const { chromium } = require('playwright');
const spki = require('fs').readFileSync(process.env.S + '/spki.txt', 'utf8').trim();
const b = await chromium.launch({
  executablePath: '/opt/pw-browsers/chromium',
  args: ['--ignore-certificate-errors-spki-list=' + spki],
});
```

Адрес открывать с `?nc=` + случайное число: WP-Optimize кеширует страницы
и отдаёт прежнюю вёрстку.

## Что снимать, а не только смотреть

Скриншот показывает, но не доказывает. К нему — числа из `evaluate`:

```js
const info = await p.evaluate(async () => {
  const wrap = document.querySelector('.waystea-hits');
  wrap.scrollIntoView();
  await new Promise(r => setTimeout(r, 1200));
  const grid = wrap.querySelector('div[style*="display:grid"]');
  const cards = [...grid.children];
  const rows = new Set(cards.map(c => Math.round(c.getBoundingClientRect().top)));
  return { ширина: Math.round(wrap.getBoundingClientRect().width),
           карточек: cards.length, рядов: rows.size };
});
```

Минимальный набор для блока: ширина блока, число карточек, **число рядов**,
размер карточки. Для ссылки — её `href`. Для текста — сам текст.

## Два размера окна обязательно

`1440×900` и `390×844`. Мобильная вёрстка ломается отдельно от десктопной,
и владелец смотрит сайт с телефона.

## Ловушки, на которых уже обожглись

- **Ширина родителя.** Elementor-контейнер с `flex-direction: column` не
  растягивает виджет. `grid-template-columns: repeat(auto-fill, minmax(...))`
  внутри родителя неопределённой ширины считает ширину по содержимому и
  схлопывается в один столбец. Изнутри блока это не лечится — нужен
  `<style>` рядом с разметкой, распирающий виджет:
  `.elementor-widget-shortcode:has(.мой-класс){width:100%!important}`.
- **Разная высота карточек.** Если названия разной длины, кнопки пляшут.
  Лечится `display:flex;flex-direction:column` на карточке,
  `-webkit-line-clamp:2` на названии и `margin-top:auto` на кнопке.
- **Кеш.** Страница может прийти прежней. `rm -f` файл перед `curl`,
  `?nc=` в адресе, при сомнении — проверять `postid-` в теле.
- **Ленивая загрузка.** На скриншоте нижний ряд картинок бывает пустым —
  это `loading="lazy"`, а не поломка. Прокрутить и подождать.
- **Ошибки PHP.** Заодно считать вхождения `Fatal error`, `Warning:`,
  `Parse error` — должно быть ноль.

## Контрольная страница

После правки, затрагивающей общий код, открыть ещё и карточку товара:
проверить, что не отвалилось соседнее (вишлист, цены, отзывы живут в том
же WPCode-сниппете 14783).

## В ответе владельцу

Писать замеренные числа, а не «стало лучше»: «восемь карточек в один ряд,
карточка 127×236, на телефоне две в ряд». И прикладывать скриншот.
