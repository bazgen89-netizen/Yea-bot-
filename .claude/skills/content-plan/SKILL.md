# Контент-план и постинг

## Перед планированием

1. `getBrandSettings` — какие аккаунты подключены.
2. `getBestTimeToPostByNetwork` — реальные слоты, а не «по опыту».
3. `getScheduledPosts` — что уже запланировано, чтобы не задваивать темы.
4. `getAnalyticsDataByMetrics` за прошлый период — какие темы зашли.

Планируй на данных, а не на общих советах по SMM.

## Рубрики

Держи баланс: продающих постов не больше трети.

- **Сорт недели** — конкретный чай из ассортимента: вкус, история, кому.
- **Как заваривать** — короткая техника: гайвань, пуэр в термосе, вода.
- **Китай без клюквы** — регион, производство, сезон сбора, факты из
  китайских источников.
- **Магазин** — новинки, поступления, точки на картах, отзывы покупателей.
- **Вопрос-ответ** — реальные вопросы из Telegram-бота и с карт.

Темы бери из того, что уже есть: новые товары Shopify, вопросы боту, свежие
отзывы с карт.

## Формат поста

- Первая строка — крючок без «Друзья!» и без вопроса в лоб.
- 400–800 знаков, абзацами по 1–2 предложения.
- Один призыв в конце, конкретный: ссылка на товар, адрес точки, бот.
- Хэштеги: 3–5, по сорту и городу, без простыней.
- Эмодзи — максимум 2 на пост, не в начале каждой строки.

## Постинг

`createScheduledPost` — по одному посту, с датой из лучших слотов.
Перед постановкой в очередь покажи пользователю список: дата, сеть, первая
строка. Планируй только после подтверждения — это публичная публикация.

`updateScheduledPost` — правки уже запланированного, не создавай дубль.

## Разбор результатов

Раз в месяц: `getAnalyticsAvailableMetrics` → `getAnalyticsDataByMetrics`.
Смотри не лайки, а охват, сохранения и переходы. Вывод формулируй как решение:
какую рубрику усилить, какую убрать, а не «показатели выросли».
