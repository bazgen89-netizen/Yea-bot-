# Креативы для чайного бренда

## Порядок работы

1. Уточни назначение: пост, сторис, карточка товара, реклама Meta, обложка на
   картах. От этого зависит формат и текст на изображении.
2. Для многошаговых видео (реклама, UGC, озвученный ролик) сначала вызови
   `get_workflow_instructions` — там протокол для конкретного типа.
3. Генерируй пачкой (`generate_image_batch`), а не по одной картинке: дешевле
   и даёт выбор.
4. Покажи варианты пользователю до публикации куда-либо.

## Визуальный язык Waystea

Держи узнаваемость, не гоняйся за трендами:

- натуральный свет, тёплые тени, никакого неона и глянцевого пластика;
- посуда: гайвань, чахай, исинская глина, стекло — без европейских чайников
  с ситечком;
- фон: дерево, лён, камень, чайная доска; чисто, без завалов реквизита;
- цвет: земляные тона, охра, зелёный чайный лист, тёмное дерево;
- чай виден по-настоящему: сухой лист крупно, пролив с паром, мокрый лист.

Чего избегать: «китайщины» с драконами и иероглифами-украшениями, стоковых
улыбок, кричащих плашек «СКИДКА 90%», нейросетевых артефактов на руках и
посуде — проверяй пальцы и края чашек перед отправкой.

## Форматы

| Куда | Соотношение | Что важно |
|---|---|---|
| Пост в ленту | 4:5 | товар крупно, место под первую строку |
| Сторис / Reels | 9:16 | ключевой объект в центре, текст не у краёв |
| Карточка Shopify | 1:1 | ровный фон, товар целиком, тень мягкая |
| Фото в карточку на картах | 4:3 | реальный интерьер, без коллажей и текста |
| Реклама Meta | 1:1 и 9:16 | текста на картинке минимум |

## Текст на креативе

Максимум 5 слов. Никаких обещаний вроде «лечит» и «омолаживает» — Meta такое
отклоняет, а для чая это ещё и неправда. Цену на картинке ставь, только если
она реально действует.

## После генерации

- Для карточек на картах фото должно лежать по публичной ссылке — тогда
  `/photo <slug> google <ссылка>` (см. скил `store-cards`).
- Для Shopify — загрузка изображения к товару.
- Для соцсетей — передай файл в `content-plan` вместе с текстом поста.

Не публикуй ничего автоматически: сгенерировал → показал → опубликовал после
подтверждения.
