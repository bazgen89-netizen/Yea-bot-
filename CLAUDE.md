# Репозиторий Yea-bot-

⚠️ **В репозитории живут два разных Telegram-бота.** Они не связаны кодом,
у них разные библиотеки, разный способ запуска и разные задачи. Прежде чем
что-то править — определи, о каком идёт речь.

| | Чайный бот (Tea Expert) | WAYSTEA ONE |
|---|---|---|
| Где | `bot.py` + `teabot/` | `waystea_one/` |
| Для кого | покупатели, вопросы про чай | сотрудники магазинов |
| Библиотека | `python-telegram-bot` | `aiogram` 3 |
| Приём апдейтов | webhook | polling |
| Хранилище | память процесса | PostgreSQL (SQLAlchemy async) |
| LLM | Groq (`GROQ_API_KEY`) | Claude (`ANTHROPIC_API_KEY`) |
| Запуск | `python bot.py` | `python -m app.main` |
| Тесты | `pytest tests` (17) | `cd waystea_one && pytest` (39) |
| Документация | `ARCHITECTURE.md` | `waystea_one/README.md`, `docs/01`–`09` |

Правило: `teabot/` и `waystea_one/` **не импортируют друг друга**. Общего кода
у них нет, и заводить его без отдельного решения не нужно.

## Что где ещё лежит

- `docs/01_PRODUCT_VISION.md` … `09_KPI_AND_REVENUE_MODULE.md` — проектные
  документы WAYSTEA ONE: продуктовое видение, операционная система, AI-слой,
  техспек, лог решений, MVP-требования, модуль выручки и апсейла.
  `06_PROJECT_LOG.md` — журнал решений владельца, на него ссылается код.
- `archive/old_tea_qa_bot/` — **устаревший снимок** монолитного чайного бота
  до рефакторинга. Это не живой код: актуальная версия чайного бота —
  `bot.py` + `teabot/`. Править архив не нужно.
- `.github/workflows/main.yml` — «Daily Tea Digest». Расписание намеренно
  отключено (скрипта рассылки нет, а `python bot.py` на CI поднимал webhook
  и перехватывал его у продакшн-бота). Не включай обратно без отдельного
  скрипта рассылки.
- `.github/workflows/waystea-keep-alive.yml` — пинг health-эндпоинта
  WAYSTEA ONE, чтобы бесплатный Render не засыпал.

## Перед пушем

Запускай тесты того бота, который правил (оба набора идут без сети, БД и
токенов):

```bash
python -m pytest tests -q                     # чайный бот
cd waystea_one && python -m pytest -q         # WAYSTEA ONE
```
