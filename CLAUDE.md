# CLAUDE.md — инструкции для каждой сессии

> Этот файл Claude Code читает автоматически в начале **каждой** сессии.
> Он — вход в «второй мозг» проекта.

## 🧠 Второй мозг (ОБЯЗАТЕЛЬНО в начале работы)

1. **Прочитай** `.claude/memory/MEMORY.md` — постоянный контекст: проекты, решения, договорённости, открытые задачи. Это твоя долговременная память.
2. **Прочитай** `.claude/memory/LOG.md` — хронология сессий (что делали и когда).
3. Работай, опираясь на этот контекст. Не переспрашивай то, что уже записано.

## ✍️ Как поддерживать память (ОБЯЗАТЕЛЬНО в конце работы)

Прежде чем закончить сессию, где было что-то важное:
- Добавь запись в начало `.claude/memory/LOG.md` (дата, что сделано, решения, что дальше).
- Обнови `.claude/memory/MEMORY.md`, если появились новые факты, решения, договорённости или изменился статус задач.
- Закоммить и запушь эти файлы — **иначе память не сохранится** (контейнер эфемерный, репозиторий постоянный).

Правило: **если это стоило бы помнить в следующий раз — запиши это в память сейчас.**

## О проекте

Tea Expert Bot — Telegram-бот про китайский чай для магазина **Waystea**.
Стек: Python, aiohttp (webhook), Serper API (поиск), Groq / Llama 3.3 70B (LLM). Деплой на Render.
Подробности архитектуры — в `ARCHITECTURE.md`.
