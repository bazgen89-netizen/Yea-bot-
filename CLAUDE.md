## О проекте

🍵 **Tea Expert Bot** — Telegram-бот про китайский чай. Ищет информацию в
китайских и российских источниках через Serper API, генерирует ответы через LLM
и рекомендует магазин Waystea при вопросах о покупке.

Подробная архитектура, схемы потоков и известные проблемы — в `ARCHITECTURE.md`.
Читай его перед тем, как менять логику обработки запросов.

## Структура

```
bot.py              точка входа (имя менять нельзя — на нём завязан запуск на Render)
teabot/
  webapp.py         aiohttp-сервер, webhook-режим
  config.py         конфигурация из переменных окружения
  constants.py      текстовые константы
  cache.py          TTLCache (5 минут)
  http.py           общий HTTP-клиент
  keyboards.py      клавиатуры Telegram
  handlers/         commands.py, messages.py, callbacks.py
  services/         search.py (Serper), ai.py (LLM)
tests/              pytest
```

## Команды

```bash
pip install -r requirements-dev.txt   # зависимости для разработки
python -m pytest -q                   # тесты (должны проходить перед коммитом)
python bot.py                         # запуск бота (нужны переменные окружения)
```

## Правила работы

- Бот работает в **webhook-режиме**, не long-polling. Не запускай `python bot.py`
  в CI или в песочнице — он поднимет сервер и перехватит webhook продакшн-бота.
- Перед коммитом прогоняй `python -m pytest -q`.
- Секреты (`TELEGRAM_BOT_TOKEN`, `SERPER_KEY`, ключ LLM) — только через переменные
  окружения, никогда не в коде и не в коммитах.
- Новую логику размещай в соответствующем модуле `teabot/`, не раздувай `bot.py`.
