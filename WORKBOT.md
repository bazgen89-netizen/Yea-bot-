# 👷 Рабочий контур: смены, регламенты, обучение

Второй режим того же бота. Клиенты как и раньше получают чайного эксперта, сотрудники из
`work_config.json` — рабочую панель. Отдельный бот и отдельный сервис не нужны.

## Как выглядит день сотрудника

| Время (МСК) | Что делает бот |
|---|---|
| 09:45 | «Доброе утро, точка Гагаринский». Кнопка **📍 Я на точке** — Telegram присылает геометку |
| — | Проверка радиуса. Дальше от точки, чем radius_m → смена открывается, но руководителю уходит уведомление |
| — | Просит **фото точки**, затем открывает чек-лист «Открытие смены» |
| — | Спрашивает, **какой чай заварен сегодня** |
| 12:30, 15:30, 18:30 | Напоминает угощать гостей заваренным чаем — особенно тех, кто уже что-то покупает |
| 13:00–17:00 (случайно) | Викторина по технологичкам, первый вопрос — по заваренному сегодня чаю |
| 17:30 | Просит впечатления о чае: вкус, как заваривал, кому зайдёт → в базу «Дегустации» |
| 20:30 | Чек-лист «Закрытие смены» |
| по кнопке | «🌙 Закрыть смену» — фиксируются часы |
| 21:00 | Руководителю уходит сводка по всем |

Просроченная задача с дедлайном → эскалация руководителю (проверка каждые 15 минут).

## Команды

Telegram разрешает только латиницу в командах, поэтому русские слова работают как обычный текст.

| Команда | Кто | Что |
|---|---|---|
| `/myid` | все | свой Telegram ID — нужен, чтобы заполнить `work_config.json` |
| `/where`, `где я` | все | прислать геометку и узнать точные координаты и расстояние до точки (смену не открывает) |
| `/start`, `меню` | сотрудник | панель с регламентами |
| `/brew`, `чай` | сотрудник | записать/сменить заваренный чай |
| `/feedback`, `отзыв` | сотрудник | записать впечатления о чае прямо сейчас |
| `/rules`, `правила` | сотрудник | что именно бот фиксирует |
| `/task Аня пересчитать банки до 18:00` | руководитель | поставить задачу |
| `/digest`, `сводка` | руководитель | сводка за сегодня |
| `/people`, `люди` | руководитель | состав и точки |

## Что и где хранится

Google Sheets, листы создаются автоматически при первой записи:

`Смены` · `Задачи` · `Чек-листы` · `Дегустации` · `Викторина` · `Чай дня`

Если `GOOGLE_SHEET_ID`/`GOOGLE_CREDENTIALS` не заданы, бот пишет в `work_data.json`.
На Render диск эфемерный — файл пропадёт при передеплое, поэтому это только для разработки.

## Настройка

1. **Кто есть кто.** Каждый сотрудник пишет боту `/myid`, вы собираете ID.
2. `cp work_config.example.json work_config.json` — вписать точки (широта/долгота/радиус),
   людей, роли (`boss`/`staff`), рабочие дни (`0` = понедельник). В примере уже три точки —
   Гагарина, Черёмушки, Студёная (гастромаркет) — и по одному сотруднику на каждую.
   Координаты стоят нулями: пока они нули, геопроверка не работает (смена откроется откуда угодно),
   и бот пишет об этом в лог при старте.
3. `cp tech_cards.example.json tech_cards.json` — свои технологические карты и вопросы.
4. Регламенты: встроенные (открытие, банки, чистота, дегустация, закрытие) можно
   переопределить файлом `regulations.json` — формат см. `teabot/work/regulations.py`.
5. Google Sheets: сервисный аккаунт → JSON-ключ в `GOOGLE_CREDENTIALS` (одной строкой),
   ID таблицы в `GOOGLE_SHEET_ID`, таблицу расшарить на e-mail сервисного аккаунта.
6. Первый запуск с `SEND_CONSENT_NOTICE=1` — бот разошлёт сотрудникам уведомление о том,
   что фиксируются время и геометка.

### Как получить точные координаты точки

Координаты из ссылки на Яндекс.Карты — это центр карты, а не сама точка; при
городском масштабе расхождение достигает сотен метров, и геозона в 150 м работает
неверно. Порядок такой:

1. Вписать в конфиг примерные координаты (хоть из ссылки — у Яндекса в `ll=` порядок
   «долгота, широта», а в конфиг нужна сначала широта).
2. Прийти на точку, написать боту `/where` и отправить геометку — бот ответит
   своими координатами и расстоянием до записанных.
3. Подставить в конфиг координаты из ответа бота. Проверить ещё раз `/where` —
   должно быть «внутри зоны», расстояние в пределах десятков метров.

### Переменные окружения

| Переменная | Назначение |
|---|---|
| `GOOGLE_SHEET_ID` | ID таблицы (из её URL) |
| `GOOGLE_CREDENTIALS` | JSON-ключ сервисного аккаунта одной строкой |
| `WORK_CONFIG_PATH` | путь к `work_config.json` (по умолчанию рядом с ботом) |
| `TECH_CARDS_PATH`, `REGULATIONS_PATH` | пути к картам и регламентам |
| `SEND_CONSENT_NOTICE` | `1` — разослать уведомление при старте |

Без `work_config.json` рабочий контур выключен: бот работает ровно как раньше.

## Про геометку — важное

- Геометка запрашивается **разово, по нажатию кнопки**, только при открытии смены.
  Постоянного отслеживания нет и не будет — оно и незаконно без отдельного согласия, и бесполезно.
- Геометку в Telegram **можно подделать** (десктоп, модифицированный клиент). Поэтому открытие
  смены закрывается связкой гео + фото точки: подделать оба разом мимоходом уже не выйдет.
- Сотрудников нужно **уведомить письменно** о том, что ведётся учёт времени и геолокации
  (ст. 86 ТК РФ, закон о персональных данных). Текст в боте — `/rules`; бумажное уведомление
  под подпись это не заменяет.
