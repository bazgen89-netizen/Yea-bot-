# Archived: old Tea Q&A bot

This bot predates WAYSTEA ONE and solves a different problem: it answers
public questions about Chinese tea using Groq's LLM API, with an affiliate
promo insert for the Waystea shop. It has no connection to the operational
system described in `docs/` (shifts, tasks, purchasing, reporting, revenue).

Kept here for reference only. Not part of the WAYSTEA ONE build — see
`docs/06_PROJECT_LOG.md`, Decision 5.
