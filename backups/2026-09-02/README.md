## Правка 1: миниатюра записи в размере large вместо full

**Что сделано.** Добавлен сниппет Code Snippets **171** «Waystea: миниатюра
записи в размере large, а не full».

**Зачем.** Виджет `jkit_post_featured_image` выводил избранное изображение
записи в полном размере. На `/krasnyj-chaj/` это был PNG 1200×1200 весом
1951 КБ — 86 % веса всех картинок страницы, без ленивой загрузки.

**Замер до и после** (сумма всех изображений страницы `/krasnyj-chaj/`):

| | вес |
|---|---|
| было | 2275 КБ |
| стало | **820 КБ** |
| экономия | 1455 КБ, −64 % |

Действует на все записи блога.

**Как откатить.** Удалить сниппет 171 или выключить его:

```
curl -X DELETE -u "<логин:пароль приложения>" \
  https://waystea.ru/wp-json/code-snippets/v1/snippets/171
```

Ничего, кроме этого сниппета, правка не затрагивает: файлы не менялись,
изображения не пересохранялись, записи не редактировались.

**Проверено после правки:** карточка товара, статья, лента блога и главная
отдают 200, изображений в полном размере не осталось нигде, галереи товаров
работают как прежде.

## Правка 2: рубрика по умолчанию и записи из «Без рубрики»

**Что сделано.**

1. Четыре опубликованные записи перенесены из «Без рубрики» (1) в «О чае» (96):
   `khranenie-chaya-doma` (15414), `chahai-gundaobej` (15407),
   `matcha-chaj` (15406), `kak-vybrat-puer` (15404).
   Черновик 15412 (дубль про Юньнань) оставлен как есть — он на удаление.
2. Настройка WordPress `default_category` переведена с 1 на 96.

**Зачем.** «Без рубрики» уже чистили раньше, но рубрика по умолчанию осталась
прежней, и каждая новая запись падала туда снова. Теперь в «Без рубрики»
ноль записей, в «О чае» — 36.

**Как откатить.**

Вернуть записи: `POST /wp-json/wp/v2/posts/<id>` с телом `{"categories":[1]}`
для каждого из четырёх id. Исходное состояние — в `posts-in-bez-rubriki.json`.

Вернуть настройку: разовый сниппет с `update_option('default_category', 1);`.

**Проверка перед правкой:** сверил все 45 записей по нормализованным названиям —
новых дублей нет, только две известные пары, обе уже переведены в черновики.
