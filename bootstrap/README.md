# Установка второго мозга

Скрипт `install-second-brain.sh` ставит базу знаний **глобально** — для всех
проектов в окружении, а не только для того репозитория, где лежит.

## Что он делает

Пишет в `~/.claude/settings.json` два хука:

- **SessionStart** — рассказывает каждой новой сессии, где лежит мозг и что
  с ним делать. Работает в любом проекте, даже если репозиторий базы не подключён:
  сессия подтянет его сама.
- **Stop** — не даёт завершить сессию, работа которой не записана. Молчит для
  сессий короче десяти минут и срабатывает один раз за сессию, чтобы разговор
  без изменений не упёрся в цикл.

Скрипт идемпотентен: повторный запуск не создаёт дублей и не затирает чужие хуки
в том же файле.

## Установка происходит сама

Ничего запускать не нужно. Хук `SessionStart` этого репозитория при первом же
старте сессии проверяет, стоят ли глобальные хуки, и ставит их, если нет.
Достаточно один раз открыть этот репозиторий в контейнере — дальше мозг
доступен во всех проектах контейнера.

Дубля не возникает: если глобальный хук уже стоит, репозиторный молчит и
говорит только глобальный.

## Необязательно: через setup-скрипт окружения

Контейнер эфемерный, поэтому `~/.claude/` не переживает пересоздание. Чтобы
установка происходила сама, впишите одну строку в **setup-скрипт окружения**
Claude Code (claude.ai/code → окружение → Setup script):

```bash
curl -fsSL https://raw.githubusercontent.com/bazgen89-netizen/Yea-bot-/main/bootstrap/install-second-brain.sh | bash
```

Так установка произойдёт ещё до того, как будет открыт хоть один репозиторий —
полезно, если в новом контейнере работа начинается сразу с другого проекта.
Раздел Environments доступен не на всех тарифах и не во всех клиентах; если его
нет, ничего страшного — работает способ выше.

> Ссылка ведёт на ветку `main`. Пока PR не влит, замените `main` на
> `claude/waystea-ru-work-wlcc84` либо влейте PR.

## Настройка

Переменные окружения, если база переедет:

- `SECOND_BRAIN_REPO` — репозиторий, по умолчанию `bazgen89-netizen/Yea-bot-`
- `SECOND_BRAIN_PATH` — папка внутри него, по умолчанию `knowledge`

## Проверка

```bash
echo '{"session_id":"test"}' | ~/.claude/hooks/second-brain-start.sh
```

Должен вернуться JSON с полем `additionalContext`.
