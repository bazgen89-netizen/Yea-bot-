# 21st.dev Magic (MCP)

Проектный MCP-сервер 21st.dev подключён через `.mcp.json` в корне репозитория.
Он даёт инструменты генерации UI-компонентов (React + Tailwind + shadcn/ui) —
полезно для веб-панелей и лендингов вокруг бота.

## Настройка

1. Получи API-ключ: https://21st.dev → Console → API Keys.
2. Экспортируй его как переменную окружения (ключ **не** коммитится в репозиторий):

   ```bash
   export TWENTY_FIRST_API_KEY="an_sk_..."
   ```

   Для постоянной работы добавь строку в `~/.zshrc` / `~/.bashrc` или в менеджер секретов.
3. Запусти Claude Code из корня проекта и подтверди подключение проектного
   MCP-сервера. Проверить статус: `/mcp` или `claude mcp list`.

## Как это устроено

`.mcp.json` объявляет HTTP-транспорт напрямую к `https://21st.dev/api/mcp`
с заголовком `x-api-key`. Обёртка `npx -y @21st-dev/magic@latest` из старых
инструкций сейчас всего лишь проксирует запросы на тот же адрес, поэтому
прямое HTTP-подключение работает без Node-процесса.

Альтернатива через stdio (если нужен именно npx):

```json
{
  "mcpServers": {
    "magic": {
      "command": "npx",
      "args": ["-y", "@21st-dev/magic@latest"],
      "env": { "API_KEY": "${TWENTY_FIRST_API_KEY}" }
    }
  }
}
```

## Troubleshooting

| Симптом | Причина | Решение |
|---|---|---|
| `401` от сервера | Ключ не задан или отозван | Проверь `echo $TWENTY_FIRST_API_KEY`, перевыпусти ключ |
| Сервер не появился в `/mcp` | Claude Code запущен не из корня репозитория | Запусти из директории с `.mcp.json` |
| Нужен npx-вариант, но не стартует | Старый Node | Обнови до актуального LTS (проверено на Node 22) |

Ключ формата `an_sk_...` даёт доступ к платному API — храни его только в
переменных окружения или секрет-менеджере, никогда в git.
