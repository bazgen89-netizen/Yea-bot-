# Автоанонс статей waystea.ru в Telegram и ВКонтакте

Каждые 2 часа GitHub Actions (`.github/workflows/crosspost.yml`) запускает `crosspost.py`:

1. Берёт 20 последних опубликованных статей через WordPress REST API (`/wp-json/wp/v2/posts`, без авторизации).
2. Для каждой площадки находит статьи, которые туда ещё не отправлялись.
3. Публикует анонс: заголовок, абзац «Коротко:» из статьи (или отрывок) и ссылку на статью.
4. Запоминает отправленные статьи в `crosspost_state.json` (хранится в кэше GitHub Actions).

При **первом** запуске для площадки все существующие статьи помечаются отправленными — архив блога в канал не выгружается, анонсируются только статьи, вышедшие после подключения.

Площадка без ключей просто пропускается — можно подключить сначала только Telegram, а ВКонтакте позже.

## Подключение Telegram-канала

1. Добавьте бота (тот же, что работает на Render — его токен уже лежит в секрете `TELEGRAM_BOT_TOKEN`) в канал **администратором** с правом «Публикация сообщений».
2. GitHub → репозиторий → **Settings → Secrets and variables → Actions → New repository secret**:
   - `TELEGRAM_CHANNEL_ID` — `@имя_канала` для публичного канала или числовой ID вида `-100…` для закрытого.

## Подключение группы ВКонтакте

Метод `wall.post` работает только с **ключом пользователя** — администратора группы; ключ доступа сообщества для публикации на стене не подходит.

1. Получите ключ пользователя с правами `wall,groups,offline` (например, через своё приложение на [id.vk.com](https://id.vk.com/about/business/go)).
2. Добавьте секреты:
   - `VK_ACCESS_TOKEN` — ключ пользователя;
   - `VK_GROUP_ID` — числовой ID группы (можно с минусом — он отбрасывается).

## Проверка

GitHub → **Actions → Crosspost Blog → Run workflow**. В логе шага «Crosspost new articles» видно, что опубликовано и какие были ошибки. Если отправка не удалась, статья не помечается отправленной и повторяется при следующем запуске.

## Чего здесь нет и почему

| Площадка | Статус |
|---|---|
| Дзен | Открытого API для публикации нет. Проверьте в «Студии Дзена» импорт по RSS: лента сайта — `https://waystea.ru/feed/` |
| Пикабу, VC.ru | Открытого API нет, автопостинг ссылок против правил площадок — только ручные публикации |
| Ответы Mail.ru | Автоматические ответы — спам и бан аккаунта; только ручные экспертные ответы |
