# Свой VPN/прокси-сервис на VPS (WireGuard)

Скрипты для быстрого развёртывания собственного WireGuard-сервера на чужом VPS —
то есть личного «выхода в интернет» через сервер, который контролируете только вы.

Это отдельный инфраструктурный сервис — он **не связан** с ботом `Yea-bot-` /
`teabot/` из корня репозитория и не запускается вместе с ним. Файлы лежат здесь
просто как готовый, версионируемый скрипт установки.

## Что понадобится

1. **VPS** с Ubuntu 22.04/24.04 или Debian 11/12, минимум 512 МБ RAM, root-доступ
   по SSH. Подойдёт любой провайдер (Timeweb, Selectel, Hetzner, DigitalOcean,
   Vultr и т. д.) — выбирайте по цене/локации дата-центра.
2. Клиентское приложение WireGuard на устройстве, с которого будете подключаться:
   - [WireGuard для iOS/Android](https://www.wireguard.com/install/) (сканирует QR-код)
   - [WireGuard для Windows/macOS/Linux](https://www.wireguard.com/install/) (импорт `.conf`)

## Установка сервера

1. Подключитесь к свежему VPS по SSH:
   ```bash
   ssh root@<IP_ВАШЕГО_СЕРВЕРА>
   ```
2. Скопируйте на сервер файлы `install.sh` и `add-client.sh` из этой папки
   (например, `scp infra/vps-wireguard/*.sh root@<IP>:~/` с локальной машины,
   либо просто вставьте содержимое файлов через `nano`).
3. Запустите установку:
   ```bash
   sudo bash install.sh
   ```
   Скрипт сам:
   - поставит `wireguard`, `qrencode`, `ufw`;
   - сгенерирует ключи сервера;
   - поднимет интерфейс `wg0` с NAT/форвардингом трафика;
   - откроет в файрволе SSH и UDP-порт WireGuard (по умолчанию `51820`);
   - создаст первого клиента `phone` и покажет его QR-код.

4. Отсканируйте QR-код в приложении WireGuard на телефоне — либо скопируйте
   файл `/etc/wireguard/clients/phone.conf` на компьютер и импортируйте его
   там же.

## Добавление ещё одного устройства

На сервере:
```bash
sudo bash add-client.sh laptop
```
Появится `/etc/wireguard/clients/laptop.conf` и QR-код для него.

## Отзыв доступа у устройства

```bash
sudo bash remove-client.sh laptop
```

## Настройки по умолчанию

Все параметры можно переопределить переменными окружения перед запуском
`install.sh` (см. комментарии в начале файла): порт, имя интерфейса, подсеть
VPN, DNS клиентов, имя первого клиента.

## Безопасность

- После установки рекомендуется отключить вход по SSH-паролю (оставить только
  ключи) и, по возможности, ограничить порт 22 списком доверенных IP.
- Регулярно обновляйте систему: `apt update && apt upgrade`.
- Каждому устройству — свой клиентский конфиг; не расшаривайте один `.conf`
  на несколько устройств одновременно (у каждого пира свой приватный ключ).
- Приватные ключи сервера и клиентов хранятся в `/etc/wireguard` с правами
  `600/700` — не выкладывайте их содержимое никуда, включая этот репозиторий.
