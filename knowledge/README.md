# База знаний

Хранилище Obsidian. Откройте папку `knowledge` как vault — ссылки `[[...]]`
построят граф. На GitHub схемы рендерятся сами.

Здесь фиксируется работа по всем проектам владельца: в чём была причина проблемы,
чем это доказано, что изменено и где лежит правка. Не список действий, а рассуждение.

> Секреты — пароли, ключи API, токены — сюда не пишутся. Только указание, где они лежат.

## Проекты

| Папка | Проект | О чём |

| [`waystea/`](waystea/) | **waystea.ru** | Интернет-магазин чая на WooCommerce: доставка СДЭК, оплата, поиск, SEO, блог |

Устройство самой базы, включая уже отвергнутые варианты —
[[Как устроен второй мозг]].

Точка входа проекта — файл `<проект>/*— обзор.md`.
Незакрытые задачи — `<проект>/Открытые вопросы.md`.

## Как завести новый проект

1. Создать папку `knowledge/<короткое-имя>/`.
2. Положить в неё `<Имя> — обзор.md` со ссылками на остальные заметки
   и `Открытые вопросы.md`.
3. Добавить строку в таблицу выше.
4. Закоммитить и запушить.

Ссылки `[[...]]` в Obsidian ищут по имени файла, а не по пути, поэтому заметки
разных проектов можно связывать напрямую — общий граф это покажет.

Процедура записи целиком — навык `/second-brain`.
