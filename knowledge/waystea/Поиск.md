# Поиск

Плагин **Advanced Woo Search 3.66**. Индекс — таблица `wp_aws_index`, ~71 700 терминов.

## Панель не закрывалась после Enter

Причина в исходнике плагина: при фокусе на поле, если в нём есть текст, панель
раскрывается заново —

```js
if (searchFor !== "") { methods.showResultsBlock() }
```

А на странице результатов поле приходит с сервера уже заполненным (`value="пуэ"`).
Панель не «не закрывалась» — она открывалась снова.

Сниппет **44**: после загрузки страницы гасит панель, если она раскрылась сама.
Мобильный полноэкранный слой закрывается штатной кнопкой плагина
(`hideMobileLayout()` возвращает форму на место в DOM), а не снятием классов.
Есть защита: не вмешивается, если человек уже печатает.

## Забытая раскладка клавиатуры

`xfq` → `чай`, `ge'h` → `пуэр`.

Работает не угадыванием языка, а проверкой по индексу: если набранное в индексе есть —
не трогаем; если нет, переводим в другую раскладку и проверяем снова; подменяем только
когда перевод что-то находит. Поэтому латинские запросы (`Camellia`, `sinensis`,
`da hong pao`) не ломаются.

Сниппет **117**. Подключено к живым подсказкам (`aws_pre_normalized_search_string`)
и к странице результатов (`pre_get_posts`).

> Форма отправляет параметр `type_aws=true` — без него страница поиска не отдаёт
> товары вообще.
