# Поисковый спрос: что реально ищут

Источник — API Яндекс.Вебмастера, `search-queries/popular`, все 592 запроса
выгружены постранично. Полная таблица рядом: `Запросы — Вебмастер.txt`.

## Доступы

- **Вебмастер — есть.** OAuth-токен рабочий, `user_id` 1066835000, логин waystea,
  хост `https:waystea.ru:443` подтверждён. Токен в заметки не пишется; он лежит
  в истории сессии, при новой сессии его надо запросить заново.
- **Метрика — нет.** Тот же токен на `api-metrika.yandex.net` даёт
  `403 access_denied`: у приложения нет прав на Метрику. Нужен отдельный токен
  с доступом «Получение статистики». Без него разрез по времени на сайте,
  глубине и отказам недоступен.
- Эндпоинта по URL (`search-urls/popular`) в API v4 **нет** — отдаёт 404.
  Связку «запрос → страница» через API получить нельзя.

## Общая картина

| | значение |
|---|---|
| запросов | 592 |
| показов | 1382 |
| кликов | 43 |
| CTR | **3,1 %** |

CTR 3 % при средней позиции 10–12 — это не проблема позиций, а проблема сниппета:
людям показывают страницу, но заголовок их не убеждает.

Выводы, которые из этого следуют:

1. **Саган-дайля — главный источник спроса**, пятая часть всех показов, 76
   вариантов запроса. И почти нулевой CTR при позиции 9–17. «Бурятский чай» (20)
   и «байкальский чай» (9) — то же растение, их надо считать вместе: ≈ 320 показов.
2. **Гео-запросы дают лучший CTR среди небрендовых** — 7,4 %. Человек, ищущий
   «китайский чай самара», кликает. Городские страницы работают.
3. **Белый и зелёный чай — ноль кликов** при 86 показах. Заголовки не отвечают запросу.
4. Часть пуэрных запросов — с хвостом `kitayskiy-chay.ru`: люди ищут конкурента
   по названию. Эти показы бесполезны, тратить на них силы не надо.

## Что исправлено

Заголовки и описания у восьми страниц были шаблонные — «Купить {название} | WAYSTEA»,
а ключевое слово равнялось названию товара в нижнем регистре. Никто не ищет
«венчик для маття шт». Переписаны под живые формулировки из отчёта:

| товар | было в ключевом слове | стало |
|---|---|---|
| Саган-Дайля 11217 | саган дайля байкальский чай | **саган дайля купить** (59 показов) |
| Венчик 12683 | венчик для маття шт | **венчик для матчи** (34 показа, позиция 22,5) |
| Юэ Гуан Бай Лун Чжу 12392 | юэ гуан бай лун чжу шт | **юэ гуан бай** (66 показов темы) |
| Най Сян 12680 | най сян цзинь сюань молочный улун | **най сян** (18) |
| Цзинь Инь Хуа 11267 | …(lonicera japonica) | **цзинь инь хуа** (10) |
| Лао Шоу Мэй 12522 | лао шоу мэй (лао бай ча) | **лао шоу мэй** (10) |
| Люй Ло 11661 | люй ло зелёная улитка | **зелёная улитка** (7) |
| Юэ Гуан Мэй Жэнь 12394 | …сяо лун чжу | юэ гуан мэй жэнь |

Отдельно: у венчика в описании стояло «Японская матча премиального качества» —
текст про чай на странице бамбукового венчика. Заменено.

Все восемь проверены на живых страницах: `<title>` и `<meta name="description">`
отдаются новые.

## Чего это не решает

Позиции сами по себе не вырастут — правка бьёт по CTR, то есть по доле кликов
с тех показов, что уже есть. При 1382 показах и росте CTR с 3 % до 8 % это
примерно +70 переходов в период. Рост показов — отдельная работа: тексты под
саган-дайля, которых на сайте почти нет, и внешние ссылки.

## Мои ошибки

- Сказал владельцу, что доступа к Вебмастеру нет, и попросил выпустить токен.
  **Токен был** — в истории этой же сессии. Проверять надо до того, как просить.
- Дважды проверял правку по выдуманному слагу товара вместо `permalink`.
  Оба раза получил пустой результат и чуть не счёл правку неудавшейся.
- Несколько раз принял `HTTP 000` и пустой ответ за сбой правки. Это сервер
  ограничивает частоту запросов; помогает пауза и повтор.
