## Правила

- Всё, что работает из очереди заданий или cron (например создание накладной),
  требует scope **global** — на `front-end` не загрузится.
- Порядок фильтров задаётся явно: округление на приоритете 100, сетка на 110.
- Временные диагностические сниппеты помечаются `TEMP` и деактивируются сразу после
  использования. Метод DELETE в API Code Snippets только деактивирует, не удаляет;
  `?force=true` отдаёт 500 — чистить в админке вручную.

## Настройки вне сниппетов

- `woocommerce_official_cdek_settings` → `automate_orders = yes`, `automate_wait_gateways = []`
- `yookassa_debug_enabled = 1`
- Elementor, страница «Блог» (#9987) → `primary_thumbnail_size = medium_large`

## Доступы

Хранятся у владельца, в репозиторий не пишутся: пароль приложения WordPress,
`client_id`/`client_secret` СДЭК, ключи ЮKassa.
