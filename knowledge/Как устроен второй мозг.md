
# Как устроен второй мозг

Заметка про саму базу знаний: почему она так устроена и что уже пробовали.

## Требование

Владелец: записывать всё, автоматически, всегда, из любого проекта, с доступом
отовсюду. Формат — Obsidian плюс граф на GitHub.

## Что выяснилось о хранении

**Переживает только то, что закоммичено в git.** `~/.claude/` живёт ровно столько,
сколько контейнер: `~/.claude/settings.json` в свежем контейнере отсутствует.
Проверено — файла не было, пока установщик его не создал.

Отсюда решение: заметки лежат в репозитории, а не в машинных настройках.

## Три механизма

1. **`CLAUDE.md`** в корне — правило попадает в контекст с первого хода.
2. **Хук `SessionStart`** — рассказывает сессии про базу и правила.
3. **Хук `Stop`** — не даёт завершить сессию, работа которой не записана.

Хука `SessionStart` оказалось мало: он только напоминает, а сессия вольна
проигнорировать. Поэтому добавлен `Stop` с `decision: block` — он возвращает
процедуру и заставляет записать.

Два предохранителя у `Stop`, оба намеренные: молчит для сессий короче десяти минут
и срабатывает **один раз за сессию**. Без второго разговор без изменений упёрся бы
в бесконечный цикл.

## Глобальная установка

Хуки в `.claude/` работают только для своего репозитория. Чтобы охватить все
проекты, есть `bootstrap/install-second-brain.sh` — он пишет хуки в
`~/.claude/settings.json`, дополняя существующие, а не затирая.

Задумывалось запускать его из setup-скрипта окружения. **Не подошло:** раздела
Environments в интерфейсе владельца нет, `claude.ai/code/environments` отдаёт
«This session could not be found».

Поэтому установку запускает сам репозиторный хук `SessionStart`: если глобальных
хуков нет — ставит их. Достаточно один раз открыть репозиторий в контейнере.
Чтобы сессия не получала инструкцию дважды, репозиторный хук молчит, когда
глобальный уже стоит.

## Свои ошибки по ходу

- **Первая версия писала только текущую сессию.** Ранняя работа (SEO, индексация,
  контент) осталась незаписанной — восстановил из транскрипта
  `/root/.claude/projects/*/*.jsonl`. Те заметки короче: реконструированы по
  итоговым сообщениям, без полной цепочки замеров.
- **Проверка ссылок ловила ложное срабатывание** на буквальный `[[...]]` внутри
  обратных кавычек. Код-спаны теперь вырезаются перед проверкой.
- **Тест Stop-хука был неверным:** отметку старта поставил двухчасовой давности,
  а заметки правил минутой раньше проверки — хук справедливо решил, что всё
  записано. Переделал на изолированной песочнице.
- **Дублирование Stop-хука.** Для `SessionStart` дублирование убрал сразу, а для
  `Stop` забыл — сессия получила напоминание дважды, от репозиторного и
  глобального. Исправлено.

## Границы, которые обойти нечем

Чат на claude.ai писать в базу не может: у него нет ни файловой системы, ни git,
ни хуков. Читать через GitHub-коннектор — может. Это устройство продукта.

Совсем новый контейнер, где работа начинается с другого репозитория и этот не
открывается вовсе, останется без хуков до первого открытия.
