# Рекламный ролик Tea Expert Bot

Вертикальный ролик 9:16, 5 сцен по 8 секунд (0:40). Здесь лежат два варианта одного и того же сценария.

## 1. `index.html` — готовый ролик прямо сейчас

Самодостаточная HTML-страница: 7 сцен с анимацией, накладка плеера, таймкод, пауза и перемотка по главам.
Открывается в браузере без сборки и без сети (кроме шрифтов Google Fonts).

Чтобы получить видеофайл — откройте страницу и запишите область экрана (кадр вертикальный, 9:16).

## 2. Воркфлоу YouArt — генеративная версия

Проект: **Tea Expert Bot — рекламный ролик**
`https://youart.ai/workflow/c788d242-b24e-415b-b97b-edb6d8dd112a`

Собран и связан: 5 нод **LTX-2.5** (9:16, 1080p, 8 с, звук включён) → нода **Video Stitch**.
Запустить не удалось: **на аккаунте YouArt закончились кредиты** («Insufficient credits»).
После пополнения воркфлоу запускается кнопкой Run без правок.

Seedance 2.0 (у него лучше нативная озвучка) требует платного тарифа — поэтому в проекте LTX-2.5.

## Сценарий

| # | Сцена | Закадровый текст |
|---|-------|------------------|
| 1 | Гайвань, пар поднимается ink-wash мазками и складывается в вопросительный знак | «Хороший чай начинается с вопроса.» |
| 2 | Листы с иероглифами кружатся вокруг растерянного человека | «Но всё самое важное о чае написано по-китайски.» |
| 3 | Карта Азии, два луча — из Юньнани и из Москвы — встречаются в центре | «Бот ищет ответ сразу в китайских и российских источниках.» |
| 4 | Карточки (термометр, песочные часы, монета) складываются вокруг чашки | «И за пару секунд отвечает по-русски: сорт, температура, время пролива, цена.» |
| 5 | Полка с блинами пуэра, карточка WAYSTEA | «А когда захотите купить, подскажем где. Спросите о чае в Телеграме.» |

Художественное направление: китайская тушевая живопись поверх плоской моушн-графики;
палитра настоя пуэра — янтарный, селадоновый, тушь, фарфоровый крем; зерно бумаги.

Озвучка в промптах прописана, но LTX-2.5 не гарантирует русскую речь — если в готовых
клипах голоса не будет, дикторский трек накладывается отдельно поверх сшитого видео.

## Что в ролике правда о продукте

Всё показанное — реальное поведение бота (см. `ARCHITECTURE.md`): параллельный поиск
в китайских и российских источниках через Serper, ответ на Llama 3.3 70B через Groq,
кэш на 5 минут, промо магазина Waystea только для вопросов о покупке.
