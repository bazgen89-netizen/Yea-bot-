# Ничего не приглушать

Вазген сказал прямо: **«надо сделать кликабельными»**. Не «покажи кнопку»,
а «чтобы работало». Это правило — про то, чего делать нельзя.

## 1. Мёртвых кнопок не бывает

Запрещено:

- рисовать кнопку и ставить ей `soon`/`disabled`, «пока не сделано»;
- красить текст в синий, если он никуда не ведёт;
- показывать поле отбора, которое ничего не отбирает;
- ставить прочерк там, где у него стоит значение, не выяснив сначала,
  откуда он его берёт.

Если элемент есть на его экране — он должен **работать**. Не успеваешь
сделать в этот заход — не рисуй его вовсе и скажи вслух, что этого пока
нет. Приглушённая кнопка выглядит как сделанная работа и не является ею;
именно за это он злится.

## 2. Куда ведёт — смотреть в их разметке, а не гадать

`web.cloudshop.ru` отдаёт разметку своих экранов **без входа**. Там прямо
написано, куда какой переход:

```bash
curl -s https://web.cloudshop.ru/ | grep -oE 'src="js/main-[^"]+"'
curl -s https://web.cloudshop.ru/js/main-XXXX.js -o main.js
grep -oE '"js/pages/[a-z/-]+\.html"' main.js | sort -u
curl -s https://web.cloudshop.ru/js/pages/journal/page/index.html
```

В шаблоне ищи `ui-sref=` и `ng-click=` — это и есть ответ «что куда
открывается». Пример из журнала:

| Поле | Переход |
|---|---|
| Магазин / Клиент | `item._go('from' \| 'to')` |
| Автор | `card.profile({staff_id})` |
| Касса | `card.register.showBox({register_id})` |
| Смена | `card.register.showShift({shift_id})` |
| Номер оплаты | `card.money_show({orderId})` |
| Счёт | `card.account_show({accounts_id})` |
| Товар | `card.catalog.get({productId})` |

Полный разбор — `docs/разбор-cloudshop.md`.

## 3. Снимки он уже присылал

**Перед тем как просить снимок — искать его в переписке.** Он присылал их
десятками, и просьба «пришлите снимок» того, что уже прислано, читается
как «я тебя не слушал». Так и вышло с панелью «Фильтр»: снимок пришёл 14
августа, а в списке до 23-го стояло «жду снимки».

Достать все присланные снимки из истории сессии:

```bash
python3 - <<'PY'
import json, base64, os
src = '/root/.claude/projects/<проект>/<сессия>.jsonl'
os.makedirs('shots', exist_ok=True)
n = 0
for line in open(src, errors='replace'):
    if '"image"' not in line: continue
    row = json.loads(line)
    msg = row.get('message') or {}
    if msg.get('role') != 'user': continue
    for c in msg.get('content') or []:
        if isinstance(c, dict) and c.get('type') == 'image':
            n += 1
            open(f'shots/{n:02d}.png','wb').write(base64.b64decode(c['source']['data']))
PY
```

## 4. Данные — из его кабинета, а не из головы

Прочерк на экране означает «данных нет». Прежде чем его поставить, надо
исчерпать способы достать значение:

- `connect-api.cloudshop.ru/docs` — опись **всех** запросов ключа (18 штук);
- поля, которых нет в справочнике, бывают в документах: себестоимость и
  цена закупки лежат в строках «Корректировки», а не в карточке товара;
- чего нет в списках, бывает поштучно: наборы отдаёт `/product/{id}`,
  хотя в общем списке их нет;
- имя может лежать в соседней записи: название кассы `…7596` — это
  магазин `…7597`.

Не нашлось — сказать словами, что именно не отдаётся и почему, назвать
запрос и код ответа. «Взять неоткуда» без этого — отговорка.

## 5. Проверка — в собранной программе

Задача закрыта, когда она работает: `npm test && npm run typecheck`,
`node scripts/build-demo.mjs --real`, открыть экран в браузере, **нажать
на то, что сделал**, и сверить снимок с его снимком рядом. Разметка,
которая выглядит правильно, но не нажимается, — не сделанная работа.
