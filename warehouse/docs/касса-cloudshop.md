# Касса CloudShop: меню и весь функционал

Что лежит в гамбургере слева внизу и что делает каждый пункт.

## Как это получено

Войти в рабочий кабинет и щёлкать там мышью я не могу — пароль от него я не
беру. Но щёлкать и не понадобилось: кассирское приложение (`/wpapp/`) отдаёт
без входа и свой код, и **свой словарь подписей**. Загрузчик словаря лежит
прямо в коде:

```js
new Request("/locale/WPAPP/".concat(lang, "/").concat(CONFIG.translation_server,
            "?version=1.53"))
// CONFIG.translation_server = "translator.cloudshop.ru"
```

то есть `https://web.cloudshop.ru/locale/WPAPP/ru/translator.cloudshop.ru` —
**453 строки с точными русскими подписями**. Компонент меню найден в том же
коде целиком. Поэтому ниже не пересказ по памяти и не догадки по скриншотам,
а то, что написано в самой программе: подписи, порядок, условия показа и
горячие клавиши.

Чего этим способом не получить: какие пункты скрыты именно у вас настройками
и правами, и как всё это выглядит. Состав и поведение — точные.

## Меню гамбургера — точный состав

Сверху вниз, как рисует сам компонент:

| | Пункт | Когда виден | Что делает | Клавиша |
|---|---|---|---|---|
| | **Карточка пользователя** | всегда | Аватар 40×40, имя, под ним роль: Владелец · Управляющий · Кассир · Кладовщик · Продавец | |
| | *разделитель* | | | |
| 1 | **Выйти** | всегда | Выход из учётной записи, уводит на экран входа | **6** |
| 2 | **Вернуться к старой версии** | всегда | Переход на прежнюю версию кассы (`/pos/home`) | |
| | *разделитель* | | | |
| 3 | **Создать возврат** / **Вернуться к продаже** | смена открыта | Переключает документ между продажей и возвратом. Подпись меняется по текущему режиму | **4** |
| 4 | **Закрыть смену** | смена открыта | Закрывает смену. Написан **красным** | **5** |
| | *разделитель* | смена открыта | | |
| 5 | **Возврат долга** | смена открыта **и** включена отсрочка | Открывает список должников (`/debt`) | **3** |
| 6 | **Журнал чеков** | смена открыта | Журнал чеков смены (`/history`) | |
| 7 | **Смены** | не на узком экране | Экран смены (`/home/shift`) | **2** |
| 8 | **Настройки** | всегда | Настройки кассы (`/home/settings/base`) | **1** |

**Горячие клавиши.** `Shift` открывает меню; при открытом меню цифры 1–6
работают как в таблице. Номер показан у пункта серой цифрой справа.
Мелочь из кода: клавиша `4` зарегистрирована и цифра у пункта рисуется, но
обработчика для неё нет — то есть значок есть, а нажатие ничего не делает.
При переходе показывается сообщение «Переход в раздел «…»».

Обратите внимание, чего в этом меню **нет**: товаров, клиентов, оборудования,
проверки документа, событий. Клиенты и товары живут на самом экране продажи,
оборудование — внутри настроек.

## Смены (`/home/shift`)

**Открытие смены.** Заголовок «Открытие смены», поле «Сумма денег в кассе».

**ИТОГИ СМЕНЫ** — что показывается:

- Сумма на начало смены · Сумма на текущий момент · Сумма на конец смены
- Сумма всех взносов · Сумма всех выносов
- Наличные · Безналичные
- Продажи: количество продаж, сумма продаж
- Возвраты: количество возвратов продаж, сумма возвратов продаж
- Выручка с учётом возвратов
- Расчётная сумма в кассе · **Расхождение по кассе**
- Касса, Дата открытия, Дата закрытия, «Открыта в …»

**Финансовые операции** прямо из смены: **Приём** · **Выдача** · **Перевод**,
с выбором операции и категории платежа.

**Сверка денег в кассе** — отдельное действие.

Внутри смены есть **Движение товара** и **Движение денег**.

**Закрытие**: «Вы действительно хотите закрыть смену?».

**Что мешает открыть смену** (готовые сообщения программы):
«Смена в данной кассе уже открыта на другом компьютере», «…уже открыта другим
пользователем», «У вас уже открыта смена на другой кассе», «Вы не прикреплены
ни к одной кассе. Обратитесь к администратору».

## Настройки (`/home/settings/base`)

Четыре вкладки: **Основные · Категории · Карточка товара · Оборудование**,
плюс «Установить настройки по умолчанию».

**Основные**

- Сортировка товара по: Наименованию · Цене · Дате изменения; по возрастанию / убыванию
- Товары с нулевым остатком: Показывать / Не показывать
- Показывать товары из скрытых категорий
- Группировка модификаций
- Звук: Включить / Отключить
- Оформление: Светлое / Тёмное
- Язык интерфейса
- Печать: Принтер чеков · Принтер А4 · Не использовать; Ширина ленты (мм),
  Размер шрифта, Отступ по краям, Печатать чек по умолчанию

**Категории** — Цвет, Размер, Скрыть / Показать категорию.

**Карточка товара** — что показывать на плитке: изображение, артикул,
штрих-код, код товара, остаток на складе. Отображение товаров: **Сетка** или
**Список**. Есть живой пример товара.

**Оборудование** — Список оборудования и Диагностика оборудования:

- Сканеры штрих-кодов (в том числе 2D — для кодов маркировки)
- Весы: МАССА-К и CAS, выбор модели и порта
- Принтер: системный, сетевой (по IP), выбор размера чека
- Фискальный регистратор, эквайринговый терминал
- ККТ: Штрих-М, Дримкас, Атол, VikiPrint
- Обмен данными с ККМ, фискализация, срок действия фискального накопителя
- Интеграции: ОФД24, Webkassa (Казахстан), Checkbox (Украина)

Два предупреждения программы: **настройки оборудования сохраняются только на
этом компьютере**, и для подключения оборудования **нужна Windows-версия кассы**
(плагин KKMSERVER).

## Журнал чеков (`/history`)

Поиск по номеру документа, фильтр, выбор дат. Продажи и Возвраты, статусы
«Оплачен» / «Документ не оплачен», автор документа. Из чека: **Создать
возврат** (в том числе на сумму), копировать, разделить чек. Предупреждение
«Возврат по этому документу уже был создан».

---

## Возврат долга (`/debt`)

Список должников, общий долг, «Закрыть долг на сумму …», «Общий долг составит
…». Правило программы: **продажи с долгом не подлежат возврату до полного
погашения задолженности**.

---

## Сам экран продажи — что там есть

В меню этого нет, но это остальной функционал кассы:

- **Поиск**: «по наименованию, артикулу, штрихкоду, коду и описанию»
- **Клиент**: поиск по имени, телефону, email и дисконтной карте; создание
  карточки — имя, телефон (международный формат), email, дата рождения, пол,
  скидка, дисконтная карта, накопительные скидки
- **Чек**: подытог, скидка (размер и процент), налог, итог, к оплате, сдача
- **Отложить чек** · **Очередь чеков** · **Отменить чек** · **Разделить**
- **Непроведенные продажи** — «после подключения к интернету продажи будут
  созданы»; касса работает без сети и досылает документы потом
- **Оплата**: наличные (с вариантами сумм), банковская карта, терминал,
  QR Яндекс Пэй, СберБанк, Альфа-Банк, Mertech QR
- **Бонусы UDS**: списание баллов, кэшбэк, карта лояльности, код или телефон
- **Маркировка**: сканирование Data Matrix, проверка, защита от повторной продажи
- **Весы**: «положите товар на весы», применить вес
- Товар по свободной цене, продавец документа, комментарий к продаже
- **Рекомендации** и «Покупают вместе»
- **Заблокировать** кассу

## Что из этого есть у нас

| В CloudShop | У нас |
|---|---|
| Выйти | «Выйти в кабинет» |
| Создать возврат / Вернуться к продаже | нет — возврат через журнал |
| Закрыть смену | есть, с Z-отчётом и расхождением |
| Журнал чеков | ведёт в «Движение товара» |
| Смены | есть, отдельный раздел |
| Настройки | ведёт в настройки компании |
| Возврат долга | нет |
| Вернуться к старой версии | не нужно |
| Горячие клавиши Shift и 1–6 | нет |
| X-отчёт без закрытия смены | **есть у нас, в CloudShop в этом меню нет** |

Ближайшее, чего явно не хватает: **переключение продажа/возврат прямо в кассе**
и **финансовые операции из смены** (приём, выдача, перевод) — в CloudShop они
делаются не выходя из кассы, у нас за ними нужно идти в кабинет.
