# Меню кассира

Что открывает кнопка «Меню» слева внизу в интерфейсе кассира.

Таблица не написана по памяти: каждый пункт нажат в собранном приложении,
и записано то, куда он привёл на самом деле. Сценарий проверки —
`scripts/audit-cashier-menu.mjs`, его можно прогнать снова после любой правки.

## Откуда взялся состав

Войти в чужой рабочий кабинет, чтобы посмотреть на это меню, нельзя, а
угадывать — значит выдать догадку за факт. Но кассирское приложение CloudShop
(`/wpapp/`) отдаёт свой собранный код без входа, и в нём лежит таблица
маршрутов — то есть перечень экранов, которые в этом приложении существуют:

```
/home            продажа, текущий чек
/return-sale     возврат продажи
/history         история чеков, /history/document/ — один чек
/clients         клиенты, /clients/create — новая карточка
/debt            долги
/home/shift      смена; /shift-open и /confirm/shift-close — открытие и закрытие
/home/catalog    товары; /home/categories/, /home/groups — категории и группы
/check-document  проверка документа
/events          события
/equipments      оборудование
/home/settings   настройки, /home/settings/base — основные
/logout          выход
```

Из них и собрано наше меню. Чего в этом списке нет — того нет и у нас.

**Что остаётся неизвестным:** точные подписи пунктов, их порядок и значки.
Маршруты говорят, какие экраны есть, но не как они названы в самой панели.
Один снимок открытого меню закроет этот вопрос.

## Что происходит по каждому пункту

| Пункт | Подпись | Куда ведёт |
|---|---|---|
| **Продажа** | текущий чек | Закрывает меню, возвращает к чеку |
| **Возврат продажи** | выберите чек | Движение товара |
| **История чеков** | | Движение товара |
| **Клиенты** | | Клиенты |
| **Долги** | | Движение денег |
| — | | |
| **Открыть смену** | сейчас закрыта | Открывает смену на свободной кассе, остаётся в кассе |
| **X-отчёт** | без закрытия смены | Показывает итоги смены, остаётся в кассе |
| **Закрыть смену** | смена №N | Спрашивает наличные, показывает Z-отчёт, остаётся в кассе |
| — | | |
| **Смены и кассы** | | Кассовый раздел / смены |
| **Товары** | | Товары и услуги / справочник |
| **Внесение и изъятие** | | Движение денег |
| **Проверка документа** | | Движение товара |
| **События** | | Движение товара |
| **Оборудование** | | Настройки / настройки компании |
| **Настройки** | | Настройки / настройки компании |
| — | | |
| **Выйти в кабинет** | | Главная |

Блок смены меняется сам: пока смена закрыта, в нём один пункт — «Открыть
смену»; после открытия вместо него появляются «X-отчёт» и «Закрыть смену».
Поэтому в панели видно 14 строк при закрытой смене и 15 при открытой.

«Выйти в кабинет» закреплён внизу панели, а не стоит последним в списке:
список прокручивается, и единственный способ уйти из кассы не должен
требовать сначала до него доскроллить.

## Разделы без собственного экрана

История чеков, проверка документа и события ведут в «Движение товара»;
оборудование — в настройки компании. Своих экранов у них пока нет, и пункт
вёл бы в никуда — а нажатие, после которого ничего не происходит, читается
как поломка. Поэтому каждый ведёт туда, где то же самое уже лежит.

## Что нашлось при проверке

Прокликивание нашло две настоящие ошибки, обе исправлены:

1. **Разделы внутри вкладок открывались на Главной.** Касса лежит поверх
   группы вкладок, и переход в «Товары» или «Движение товара» прямо из неё
   открывал группу заново — то есть с её начального экрана. Теперь касса
   сначала снимается со стека, а раздел выбирается уже изнутри группы, как
   это делает боковое меню кабинета. Заодно ушло накопление экранов: каждый
   заход в кассу и обратно добавлял в стек ещё один.

2. **Подложка перехватывала нажатия у самой панели.** Затемнение оборачивало
   панель, и в браузере это превращалось в кнопку внутри кнопки. Теперь
   затемнение — отдельный слой под панелью. Та же ошибка была в выпадающих
   списках кабинета и исправлена там же.

## Языки

Список языков и их подписи взяты оттуда же, откуда состав меню, — из кода
кабинета CloudShop, где они лежат открытым текстом:

```js
languages = {
  en: 'English',  ru: 'Русский',   uk: 'Українська', az: 'Azerbaijani',
  kk: 'Қазақ',    ky: 'Кыргызча',  uz: "O'zbek",     tr: 'Türkçe',
}
```

Переключатель в шапке предлагает те же восемь. Выбор хранится в базе (`app_state`),
поэтому переживает перезагрузку и попадает в резервную копию.

Переведён каркас: меню, шапка, заголовки разделов и Главная целиком. Содержимое
(названия товаров, имена клиентов) не переводится — оно принадлежит пользователю.
Строка без перевода показывается по-русски, а не пустой: это заметно и не ломает
экран.

**Переводы на азербайджанский, казахский, киргизский, узбекский и турецкий
стоит показать носителю языка перед тем, как включать их покупателям.**
Термины короткие и словарные, но «Cari hesaplar» вместо «Контрагенты» —
решение, которое лучше подтвердить.
