# Как собирать файл и ссылку

Их **две**, и они разные. Перепутать легко: команда одна и та же, отличается
одним ключом, — а Вазген получает файл с мелкими снимками и справедливо
говорит, что качество плохое.

## Файл, который он открывает с диска

```bash
node scripts/build-demo.mjs --real
```

Снимки крупные, 288 точек. Предела размера нет: файл открывается локально,
и его двадцать шесть мегабайт никому не мешают. Это то, что уходит ему
вложением.

## Страница по ссылке

```bash
node scripts/refresh-photos.mjs --size=208 --quality=0.8 --out=photos-208.json --from-disk
node scripts/refresh-photos.mjs --size=112 --quality=0.75 --out=photos-112.json --from-disk
# смешать: действующим крупные, архивным мелкие
node scripts/build-demo.mjs --real --photos=photos-mixed.json
node scripts/build-artifact.mjs
```

Страница по ссылке **не может быть тяжелее 16 МБ**. С крупными снимками у
всех полутора тысяч товаров выходит двадцать шесть, поэтому набор
смешанный: у действующих товаров 208 точек — это те, которые он открывает, —
а у архивных 112, они видны только значком сорок на сорок в списке.

Половина снимков (492 из 942) принадлежит архивным товарам, поэтому размен
выгодный: место уходит туда, куда он смотрит.

## Порядок

Сперва файл, потом ссылка — иначе в `dist-demo/index.html` останется
сборка для ссылки, и вложением уедет она.
