# Кабинет CloudShop против нашего: полная карта

Прошлая версия этого документа описывала пять разделов. Их у CloudShop
**135 экранов**. Ниже — все, раздел за разделом, с отметкой, что есть у нас.

## Как это сверено

У AngularJS-приложения все экраны объявлены в одном месте — таблице состояний
`$stateProvider`, и она лежит в бандле, который сайт отдаёт без входа. Оттуда
взяты адрес, заголовок и требуемое право каждого экрана. Названия разворачивались
по словарю подписей (`/locale/WAPP/ru/…`, 1475 строк).

```bash
curl https://web.cloudshop.ru/js/main-b85f39022b.js          # 930 КБ, таблица состояний
curl https://web.cloudshop.ru/locale/WAPP/ru/translator.cloudshop.ru   # подписи
curl https://web.cloudshop.ru/js/pages/reports/_inner.html   # шаблоны тоже открыты
```

Поэтому список полный, а не «что вспомнилось». Чего в нём нет — того нет и
в их кабинете.

Обозначения: **✅** — есть у нас · **◐** — есть частично · **✖** — нет.

**Роли и права.** ✅ Те же пять ролей и те же 18 прав. Роль задаёт права,
свой набор пишется только если отличается от роли. Меню — и в кабинете, и на
телефоне — собирается под права: раздел, на который нет права, не показывается,
а не приглушается. Кто работает, выбирается на экране сотрудников; код —
защита от чужого нажатия, а не от подбора, и на поле это написано.

**Чего ещё нет:** отдельного входа при запуске (программа открывается сразу,
пока сотрудник не выбран) и экрана `/permission-denied`.

По тому, что мешает работать чайной каждый день:

   Цен по магазинам и модификаций пока нет.

3. ✅ **Просмотр документа** из журнала, с отменой.
4. ✅ **Сотрудники и права** — пять ролей, 18 прав, меню под права.
5. ✅ **Инвентаризация и корректировка** отдельными документами.

Дальше по тому, что мешает работать:

1. **Вход при запуске** — сейчас программа открыта, пока сотрудник не выбран
   вручную. Без входа права держатся на честном слове.
2. **Цены по магазинам и модификации** товара — остаток от карточки.
3. **Непроведенные документы** — целый раздел, которого нет.
4. **Редактор цен** — массовая смена цен.
5. **История движения по одному товару** отдельным экраном.

## Как перепроверить

```bash
npm run web:build
node scripts/audit-app.mjs             # обход кабинета и телефона
node scripts/audit-cashier-menu.mjs    # меню кассира
```

Разбор ложится в `dist/audit/`. Если после правки таблица разойдётся с этим
документом — врёт документ, и переписывать надо его, а не наоборот.
