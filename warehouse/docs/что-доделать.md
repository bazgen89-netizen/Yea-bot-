# Кабинет CloudShop против нашего: полная карта

Прошлая версия этого документа описывала пять разделов. Их у CloudShop
**135 экранов**. Ниже — все, раздел за разделом, с отметкой, что есть у нас.

## Как это сверено

У AngularJS-приложения все экраны объявлены в одном месте — таблице состояний
`$stateProvider`, и она лежит в бандле, который сайт отдаёт без входа. Оттуда
взяты адрес, заголовок и требуемое право каждого экрана. Названия разворачивались
по словарю подписей (`/locale/WAPP/ru/…`, 1475 строк).

```bash
curl https://web.cloudshop.ru/js/main-b85f39022b.js          # 930 КБ, таблица состояний
curl https://web.cloudshop.ru/locale/WAPP/ru/translator.cloudshop.ru   # подписи
curl https://web.cloudshop.ru/js/pages/reports/_inner.html   # шаблоны тоже открыты
```

Поэтому список полный, а не «что вспомнилось». Чего в нём нет — того нет и
в их кабинете.

Обозначения: **✅** — есть у нас · **◐** — есть частично · **✖** — нет.

отрицательный остаток · нулевая себестоимость · общий остаток меньше
минимального · не продаются 3 месяца · товары со скидкой · истёк срок годности ·
истекает в течение 7 дней. Плюс свои пресеты: сохранить, назвать, удалить.
У нас фильтров нет вовсе — кнопка «Фильтр» нарисована и молчит.

**Срок годности** — целое поле товара, которого у нас нет, и на нём завязаны
три фильтра и предупреждение «{val} поз. с истёкшим сроком годности».

И одну свою ошибку: двенадцатый отчёт «Оценка склада» я в прошлый раз выбросил.

## С чего начинать

По тому, что мешает работать чайной каждый день:

1. **Карточка товара** — наценка, НДС, срок годности, цены по магазинам,
   модификации. Самое частое действие в программе.
2. **Фильтры каталога** с их пресетами — кнопка нарисована и молчит, а
   «отрицательный остаток» и «нулевая себестоимость» у вас на 224 и 586 позициях.
3. **Просмотр документа** из журнала — сейчас в документ нельзя заглянуть.
4. **Сотрудники и права** — без них нельзя пустить за кассу кого-то ещё.
5. **Инвентаризация отдельным документом** — сейчас остаток правится в карточке
   поштучно.

## Как перепроверить

```bash
npm run web:build
node scripts/audit-app.mjs             # обход кабинета и телефона
node scripts/audit-cashier-menu.mjs    # меню кассира
```

Разбор ложится в `dist/audit/`. Если после правки таблица разойдётся с этим
документом — врёт документ, и переписывать надо его, а не наоборот.
